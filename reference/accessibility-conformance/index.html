Accessibility Conformance Report: Action Stations

VPAT 2.5 Rev, Revised Section 508 Edition (WCAG 2.2 Level A and AA, Revised 508 Chapters 3, 5 and 6)
Product Action Stations (machine name actionstations)
Version evaluated 0.6.2 (tests run against the main branch after v0.6.1, commit 1387918b)
Report date 2026-11-02
Product description A local-first desktop application (Electron) that generates tabletop exercises, with a phone, tablet or laptop web page for live-play participants and exported PDF, Word and Excel documents
Contact for accessibility problems Open an issue at github.com/actionstations-ai/actionstations
Template ITI VPAT 2.5 Rev (508 edition). This is the vendor’s own evaluation, not a third-party audit.

Scope: three products evaluated separately

Section titled “Scope: three products evaluated separately”
Product What it is Evidence in the repository
Desktop app The Electron application on Windows, macOS and Linux (the renderer, a React web UI in a Chromium window) e2e/a11y.spec.ts, scripts/check-contrast.mjs
Player page The web page participants open in a browser during live play (src/player/, served by the facilitator’s computer or a relay) e2e/live/player-a11y.spec.ts, src/player unit tests
Exported PDFs PDFs the app writes: briefing, handouts, player injects, MSEL, inject deck, handbook, EEG packet, survey forms, AAR/IP, inject media PDFs, and large-print copies docs/guides/translation-and-accessibility.md, scripts/check-pdf-accessibility.mjs, src/main/render/window.ts

Word (.docx) and Excel (.xlsx) exports, the project website, and the guides in docs/guides/ are not evaluated in this report (see “Not evaluated” at the end).

Terms

Section titled “Terms”
  • Supports: the functionality meets the criterion with no known defects, on the evidence listed.
  • Partially Supports: some functionality does not meet the criterion, or the criterion has only been partly evaluated. The remarks say which.
  • Does Not Support: the majority of functionality does not meet the criterion.
  • Not Applicable: the criterion is not relevant to the product.

Evaluation methods used

Section titled “Evaluation methods used”
  1. Automated: axe-core through @axe-core/playwright, with the tags wcag2a, wcag2aa, wcag21a, wcag21aa, wcag22aa and best-practice.
    • Desktop: e2e/a11y.spec.ts audits every screen in light and dark mode against a seeded project (documents, a scenario with rendered injects, packs, live connection, settings) and fails on any violation.
    • Player page: e2e/live/player-a11y.spec.ts audits every screen in light and dark, on a phone viewport, at 100 % and 200 % zoom, plus the end screen.
  2. Scripted keyboard and layout checks (Playwright) in the same files: visible focus on every tab stop, no keyboard traps, dialogs take focus, close on Escape and return focus, a keyboard-only walkthrough (new project to export; for the player page, joining), a 200 % zoom check that no control is clipped or unreachable, no horizontal scroll, and targets of at least 24 px on the player page. Empty and error states are checked for next-step text.
  3. Contrast check: node scripts/check-contrast.mjs tests every design-token color pair the renderer’s stylesheets use, in light and dark, at 4.5:1 for text and 3:1 for UI boundaries and focus rings. The player page imports the same tokens.
  4. PDF checks: Chromium’s tagged-PDF output is switched on for every export (generateTaggedPDF in src/main/render/window.ts). The end-to-end translation test checks the language tag and tagged structure of the Spanish packet, injects and survey form. scripts/check-pdf-accessibility.mjs runs veraPDF (PDF/UA-1) when veraPDF is installed. No veraPDF run is recorded (#501), so PDF/UA conformance is not claimed.
  5. Design review against the specs: NFR-3 of the player page spec (docs/specs/0411-player-page.md), ADR-0033, ADR-0055, spec 0435.

Not done: no recorded testing with a screen reader (NVDA, JAWS, VoiceOver, Narrator), screen magnifier, speech-recognition software or switch device; no usability testing with people with disabilities; no third-party audit. Automated tools find only part of the WCAG failures, so “Supports” below means “no defect found by the checks above and none known”, not “verified with assistive technology”.

Known exceptions

Section titled “Known exceptions”
Item Product Criteria Status
Exported PDFs are fixed-layout pages (Letter size). They do not reflow at 320 px or 400 % zoom. A large-print copy (18 pt, one column) is offered for the briefing, handouts and player injects only. Exported PDFs 1.4.4, 1.4.10 By design.
PDF/UA conformance has not been tested; veraPDF was not available. Text generated by CSS (page numbers, the stamp) is not tagged. Running headers and footers are page text and may be read on every page. Exported PDFs 1.3.1, 4.1.2, 504.2.2 Known limits of Chromium’s PDF writer.
AI-generated video clips have no audio description. Video has captions only when the inject has voice lines. Player page, desktop, media 1.2.2, 1.2.3, 1.2.5 Open.
No person has tested the desktop app, the player page or the PDFs with a screen reader and recorded the result. The guide asks users to check a packet with VoiceOver or NVDA. All Several; see the tables Open.
Features driven by a pointer (map pin placement and similar) have not been checked for a keyboard or single-pointer alternative. Desktop app 2.1.1, 2.5.1, 2.5.7 Not evaluated.
The app’s own screens are English only. Player material (briefing, handouts, injects, participant surveys) can be exported in Spanish after a person reviews the translation. All None (3.1.1 and 3.1.2 are met) Listed for buyers who need other interface languages.

How to check this yourself

Section titled “How to check this yourself”
  • Desktop: pnpm e2e e2e/a11y.spec.ts (reports go to .tmp/a11y/; A11Y_REPORT=1 records violations without failing) and node scripts/check-contrast.mjs.
  • Player page: pnpm exec playwright test e2e/live/player-a11y.spec.ts.
  • PDFs: node scripts/check-pdf-accessibility.mjs <folder or PDF> with veraPDF installed; open a packet with VoiceOver or NVDA and list headings.
